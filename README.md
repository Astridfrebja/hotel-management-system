Hotel Management System

University project developed in C# and .NET.

Overview

This project consists of multiple applications that communicate through a shared database to support hotel administration, booking management and service task handling.

Technologies

* C#
* .NET
* ASP.NET MVC
* Entity Framework Core
* SQL Server
* .NET MAUI


Note

Database credentials and connection strings have been removed from the repository. A local or custom SQL Server configuration is required to run the project.
